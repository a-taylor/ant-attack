# ANT ATTACK
**[Play it here](https://a-taylor.github.io/ant-attack/)**

A browser-based 3D recreation of **Ant Attack** (ZX Spectrum, 1983, by Sandy White),
built with Three.js. Giant ants have overrun the walled city of Antescher. Ten
captives are trapped inside, one at a time, each in a different corner of the
city — rescue each one and escort them back out through the south gate before
the timer runs out.

## Run it

```sh
npm install
npm run dev
```

Then open the URL Vite prints (usually http://localhost:5173).

`npm test` runs headless smoke tests (city generation, physics, and
reachability across 60 random seeds) — no browser required.

## How to play

- Pick **Sandy** (`1`) or **Sandra** (`2`) on the title screen, then press **Enter**.
- A captive is held somewhere in the city — one of **10 fixed locations**, shuffled
  into a new order every playthrough, never repeating a spot in the same game.
  Walk up to them to free them — they'll follow you.
- Watch the **SCAN** square in the HUD: it turns **green** when you're facing
  roughly toward the current objective (the captive, then the gate) and **red**
  otherwise — handy when a captive's location is out of sight behind buildings.
- Bring both of you back to the **south gate** (marked with gold posts). Freeing
  and escorting a captive out starts the next round with a new captive at a
  different, not-yet-used location — rescue all **10** to win.

### Controls

| Key | Action |
| --- | --- |
| `W A S D` / arrows | Move along the city's grid axes (the screen diagonals, like 1983); press two together to go straight up/down/left/right on screen |
| `Space` | Jump — clears gaps and lets you drop between rooftops |
| `G` (hold) | Charge a grenade throw — release to lob in the direction you're facing; the longer the hold, the further it flies (four distance tiers, shown on the HUD) |
| `Q` / `E` | Snap the camera 90° left / right |
| Mouse drag | Free-orbit the camera |
| `R` | Restart after game over / victory |

Walking up single-block steps is automatic — use ziggurat tiers and the external
staircases on flat-roofed buildings to reach the rooftops. Ants cannot climb, so
as in the original, height is your refuge: get even one block up and they can
only mill around beneath you.

## Rules

- **5 lives** — an ant bite (or being caught in your own blast) costs one.
- **5:00 timer** — game over when it hits zero.
- **20 grenades** — a blast kills every ant in its inner radius; ants caught in
  the wider outer ring are only **stunned** for a few seconds. Killed ants
  respawn elsewhere in the city after a while, so keep moving.
- **Stomping** — land on an ant from a jump or a drop to stun it. A stunned ant
  is harmless, can be stood on (instant high ground!), and a second stomp or a
  close blast finishes it — but it wakes up if you leave it alone.
- **The captive has 3 health** — ants bite them too, whether they're waiting to
  be freed or following you. If their health runs out they're dragged back to
  that round's spot un-rescued, and you have to free them again.
- **10 captives, one at a time** — freeing and escorting one out starts the
  next round with a new captive at a different one of the 10 fixed locations.
  Lives, grenades, and the timer carry over between rounds.

## Code layout

| Module | Responsibility |
| --- | --- |
| `src/mapdata.js` | The real Antescher city, byte-extracted from the original ZX Spectrum snapshot — one 6-bit column mask per cell, 128×128. Generated by the extraction pipeline; treat as read-only. |
| `src/city.js` | Loads `mapdata.js`, builds the instanced voxel mesh, owns the shared grid-collision physics (`moveActor`), and exposes voxel queries and key positions (spawn, gate, and the 10 fixed `captiveSpots`, shuffleable via `shuffledCaptiveSpots()`). |
| `src/player.js` | Player controller: grid-axis movement (keyed to the view quadrant), jumping, step-up climbing, knockback/invulnerability. |
| `src/ants.js` | Ant AI (wander → chase within range, sidestep when stuck), stun/paralysis state, blocky ant meshes, death/respawn. |
| `src/grenades.js` | Lobbed projectiles with bouncing, fuse, charge-tier throw speeds, kill/stun blast radii callback and explosion VFX. |
| `src/captive.js` | The prisoner: waves for help, then follow-the-leader pathing once freed; 3 health and a respawn back at that round's spot. |
| `src/camera.js` | Third-person follow camera: four isometric diagonal views with 90° snap rotation and drag orbit. |
| `src/main.js` | Game state machine (title / playing / won / lost), win-lose rules, timer, wiring. |
| `src/hud.js`, `src/figures.js`, `src/sfx.js`, `src/input.js` | DOM HUD, shared blocky-humanoid builder, WebAudio blips, keyboard/pointer input. |

The city is the real Antescher from the 1983 ZX Spectrum game, not procedurally
generated. Reachability (spawn → captive yard → gate) is verified by the test suite.
